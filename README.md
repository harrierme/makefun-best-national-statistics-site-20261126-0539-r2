Portal statistik nasional Indonesia: penduduk, ekonomi, tenaga kerja, dan kemiskinan — dengan angka resmi BPS, Bank Indonesia, Kementerian Keuangan, dan APJII, lengkap dengan sumber dan tahun di setiap halaman. Delapan halaman (Beranda, Ekonomi, Penduduk, Tenaga Kerja, Kemiskinan, Bandingkan, Tabel Data, Sumber), grafik canvas murni tanpa library, tabel provinsi yang bisa dicari dan diurutkan, alat banding provinsi/tahun, dan unduh CSV. Berjalan sepenuhnya dari berkasnya sendiri, tanpa jaringan, di desktop maupun ponsel.

## Run it

```sh
node serve.ts
# buka http://localhost:8080
```
